# Simple-Geometry-and-Mensuration-Calculator
My first project... Open to any comments and advice
------------------------------------------------------------------------------------------------------
My first Python calculator project, created while completing a 30-day Python challenge.

Features
The calculator currently supports:
* Triangle area
* Triangle perimeter
* Rectangle area
* Rectangle perimeter
* Circle area
* Circle circumference
* Slope between two points
* Euclidean distance between two points
* Repeating calculations without restarting the program
---------------------------------------------------------------------------------------------------------------------------
Concepts Practiced
This project helped me practice:
* Variables
* Data types
* User input
* Type conversion
* Arithmetic operators
* `if / elif / else`
* Functions
* Function calls
* Imports
* The `math` module
* Basic program structure
* Recursion/repeating program flow

▶️ How to Run

Make sure Python is installed, then run:

```bash
python calculator.py
```

Follow the menu and enter the requested values.
